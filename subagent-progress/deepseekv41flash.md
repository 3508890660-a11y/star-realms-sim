# deepseek v4.1flash · 三段涨潮

脚本：`scripts/agent-deepseekv41flash.js`（零依赖，ES module，导出 `meta` 与 `chooseAction`）

## 一、策略名称与选择理由

**策略名称：三段涨潮（Three-Phase Tide）**

1v1 的胜负只有一条线——权威。基础盒 50 点权威、双方每回合抽 5 张，再加上本引擎的两个硬事实：

- 回合结束时 `damage` 会被整体清空，基地掉血不跨回合；
- 前哨在场时正面完全不可攻击，而伤害不能累积，所以一座「打不掉的前哨」等于让对手整回合的战斗作废。

这两点决定了纯快攻很难在 10 回合内结束，而纯经济又会被对手的稳定输出惩罚。真正占优的是**按回合切换资源结构**：先把贸易曲线抬起来，再把贸易换成前哨与高战斗效率牌，最后用两三个高战斗回合把优势一次性兑现。节奏像涨潮，一段比一段高，每段都有明确的退出条件，因此叫「三段涨潮」。

## 二、核心思路

脚本为每张牌维护一份价值表，字段是：贸易 / 战斗 / 权威 / 抽牌、是否基地与防御、是否前哨、可压缩牌数、可销毁交易行牌数、一次性附加分、销毁收益、是否复制类、是否多选一。买入时按同一张表在三个阶段使用不同权重：

| 阶段 | 触发 | 权重取向 | 目的 |
|---|---|---|---|
| 涨潮（约 1–5 回合） | `econ = 1 - (turn-1)/7`（仅殖民战争时 /6） | 贸易 `+1.0 × econ`，压缩牌额外加分 | 把每回合贸易推到 5–7 |
| 筑堤（约 5–12 回合） | 过渡区 | 战斗 `+0.85 × (1-econ)`，前哨按威胁加权 | 建立打不掉的防线与稳定输出 |
| 决堤（约 12 回合后或对手 ≤ 20） | `finish = (20-对手权威)/12` | 战斗 `+0.6 × finish`，斩杀优先 | 把资源差换成权威差 |

三个贯穿全程的修正项：

1. **牌库平均价值门槛**：`floor = clamp(牌库平均价值 + 0.1, 2.4, 6.2)`。只买不弱于自己牌库平均水平的牌，既不在后期买废牌稀释牌库，也不因为门槛过高把当回合贸易白白浪费（贸易回合末清零）。
2. **伤害竞赛修正**：自己权威落后对手时（`race`）与对手场面价值高时（`threat`），提高战斗与前哨权重。
3. **基地重复系数 1.28**：基地主要能力每回合都能用，且伤害不跨回合使它很难被磨掉，所以基地的每回合产出按可重复使用折算；前哨再额外 +2.6。

## 三、动作优先级

每个决策点是一次「取最高分」的派发，严格按下列相位推进，前一个相位没有合法动作才进入下一个：

1. **待决动作**（弃牌 / 指定弃牌 / 强制销毁 / 事件选择）优先处理。
2. **打出**：先基地（为「两座/三座基地」的加成与同盟铺垫），再抽牌牌，复制类（隐匿针舰、隐匿尖塔）与虫群世界放最后，保证复制目标已进场。全部手牌都会打出，因为所有牌的正向效果都无需额外代价。
3. **能力**：主要 → 同盟 → 可选 → 销毁。
   - 主要能力只要有正向价值就发动；多选一基地（贸易站、易货世界、防御中心、边疆空间站、回收空间站、虫群世界）按「缺贸易 / 缺战斗 / 缺权威 / 虫群数量」择项。
   - 可选的「销毁自己一张牌」只挑低价值目标，并且优先弃牌堆——此时手牌已经打完，等于免费压缩牌库。
   - 可选的「销毁交易行」只在对手买得起的高价值牌上使用，避免帮对手清场。
4. **攻击**：
   - 能斩杀先斩杀，并且只投入恰好足够的战斗，多余战斗留给其他目标；
   - 正面可攻击时一律打脸（伤害永久，基地掉血会清零）；
   - 正面被前哨封锁时，只打「本回合能打掉」的前哨；否则退而拆对手最贵的基地止损；
   - 绝不磨血：打不穿的基地一次都不碰。
5. **购买**：在合法购买里选价值最高且过门槛的一张；回合内会反复进入本相位，直到没有合格目标。剩余 2–4 贸易且无牌可买时，最多补 3 张探索者。
6. **预留（仅 2V2）**：攻击与购买都结束后，把剩余贸易/战斗全额转给队友。
7. **结束回合**。

## 四、模式与扩展适配

- **standard**：主战场。先手 3 张、后手 5 张的处理完全一致，因为所有判断都基于当前资源与场面，不假设固定手牌数。
- **ffa**：攻击目标先看能否斩杀，否则集火权威最低的对手；弃牌类效果指定「手牌少且权威高」的目标，干扰最大。
- **hunter / firstBlood**：不自己计算邻接关系，只使用引擎给出的合法攻击动作；没有可攻击目标时不会空转，直接进入购买或结束回合。
- **team2v2**：所有「对手」按队伍过滤，队友不会成为攻击或干扰目标；队友的前哨同样保护全队（视为对手防线）；回合末把剩余资源预留，两个资源都转时优先转贸易。
- **core / colonyWars / events 任意组合**：卡表覆盖基础盒与殖民战争全部卡牌，未知卡牌用文本兜底解析（只取第一句主效果）；事件牌不会进入购买列表，不影响购买逻辑。只开殖民战争时把经济窗口从 7 回合收窄到 6 回合，因为该牌包低费牌多、对局更短。

## 五、事件与 2V2

**事件**（`eventChoice`）：

- **黑洞**：弃牌只是进弃牌堆，不是永久损失，所以永远弃满两张，只按牌面价值挑最低的两张。
- **轨道轰击**：比较「失去 6 权威」与「摧毁自家最便宜基地」；权威见底（≤12）或掉 6 会逼近 1 点时强制拆基地。
- **彗星**：只销毁低价值牌（优先弃牌堆），没有值得销毁的牌就选空目标。
- **跃迁**：把抽到的三张里最不重要的两张放回牌库顶，并让两者中较好的那张在最上面。
- 峰会 / 类星体 / 超新星 / 贸易任务没有待决选择，由引擎直接结算，脚本只受影响于结算后的资源变化。

**2V2**：共享权威使「斩杀线」按队伍权威计算（视图里已同步）；攻击目标优先选择没有前哨的一方；资源预留放在攻击与购买之后，避免把本回合还要用的战斗提前送走。

## 六、取舍与已知弱点

1. **卡表是静态估值**。价值来自人工判断，不是搜索结果；遇到极端交易行（例如全是大基地）时，购买顺序可能不是最优。
2. **先打光手牌再做能力**，会牺牲少数「需要手牌做费用」的能力：回收空间站、补给站、轨道平台的弃牌换资源在脚本里基本用不上。换来的是资源结算顺序绝对安全、不会因为过早弃牌少打一张牌。
3. **只开殖民战争时明显偏弱**。本地对内置 `tactical` 的批量冒烟里，基础盒约 76%、基础盒+事件约 87%、基础盒+殖民战争+事件约 59%–64%，而只开殖民战争只有约 35%–45%。原因是该牌包节奏更快、低费牌更多，而三段曲线的经济窗口仍按基础盒校准。
4. **单步贪心**。每次只评估当前最优动作，没有做「这回合先买 A 还是先买 B」的跨步推演，也没有为下回合保留资源的概念（贸易本来也不保留）。
5. **销毁能力偏保守**。只在能凑出斩杀、能拆掉打不动的前哨、或牌本身价值很低时才销毁，因此会错过一部分「现在销毁换节奏」的机会。
6. **混战政治**。ffa 里固定集火权威最低者，可能在两家互耗的局面里被对手联手针对；这是简化目标选择带来的代价。
7. **不读取对手手牌**（引擎也不会给），所有威胁评估都基于公开的场上牌、权威与牌库数量，无法预判对手手里的爆发。

## 二、新增 3V3 模式适配

### hydra3（三头龙，共享 100 权威）

- **敌友**：队友 = 同 `team` 且未阵亡的座位，0/2/4 与 1/3/5 两队各 3 人，判定不依赖人数常量。
- **血线归一化**：`startAuthorityOf()` 对 hydra3 返回 100，危险度/斩杀线改用**比例**（`authority / 起始权威`）而不是绝对值。
  否则「80 权威」在 50 权威模式里是碾压、在 100 权威模式里只是略优，旧脚本会把 100 血的三头龙当成快死的对手。
- **节奏**：经济段长度 `period = 7 × (起始权威/50) × 1.05`，hydra3 约 14 回合，贸易权重衰减更慢；不会在第 6 回合就全面转战斗。
- **合击与补刀**：基地伤害留到队末，所以 `defLeft()` 会如实扣掉队友留下的 `view.damage`；能一刀打穿就收掉，
  打不穿但只差 1–2 点的**敌方前哨**允许磨刀，交给紧接着行动的队友补最后一刀。
- **资源移交**：整队轮流意味着下一位队友的 `beginTurn()` 立刻把 `reserve` 加进资源池，所以换手前的剩余战斗/贸易
  一律 `transfer` 给「座位比我大的最小队友」（3 人队环形相邻即其余两名队友），优先战斗、优先最大额。

### emperor（大将战，权威在个人）

- **血线**：读 `view.players[i].authority`（大将 60 / 提督 50），`view.teams[].authority` 在大将战里恒为 0，绝不使用。
- **目标**：可打谁、能指定哪座基地，**完全信任 `legalActions`**，不按座位奇偶或对位表推导；提督只能打对位提督、
  对位阵亡后才解锁大将这条规则由引擎过滤，脚本只做选择。
- **击杀权重**：击败敌方大将 = 直接获胜，致命一击里给 +40 的额外权重；击败提督只当作「削掉一份经济」。
- **moveCard**：花 1 贸易把弃牌堆一张牌交给相邻队友。脚本只在**攻击、购买都已无牌可打**（贸易本来会清零浪费）
  且牌面价值 ≥ 3.2 时才用，并且优先交给紧接着行动的队友；送侦察艇这类低价牌一律不做。
- **防御溢价**：个人权威更脆，前哨/基地在购买时额外 +0.8 权重。

## 三、新牌包与新动作适配

- **6 个牌包任意组合**：`view.expansions.sets` 只用来判断节奏（例如「只开 colonyWars」仍走快节奏分支），
  不假设交易行卡名集合固定；交易行长度一律用 `view.tradeRow.length` 的循环写法，空位 `null` 逐位判空。
- **`double:true` 的 `ally`**：引擎把双同盟也暴露成 `ability:'ally'`，额外带 `double:true`。脚本把它当作**第二次同盟机会**，
  排在普通同盟之后使用（同一张卡一回合可以拿两次同盟收益），并在打分时略微降权，避免为了双同盟而放弃主要能力。
- **`moveCard`**：见上，作为「贸易无其他用途时」的收尾动作，不属于主循环早期相位。
- **带 `choice` 的动作**（`play` 与 `ability` 都可能带）：把卡面 `选择：A 或 B` 拆成支路，按当前三段权重逐支估值
  （贸易权重随 `econ`、战斗权重随 `1-econ`、权威权重随 `danger`），未知卡也能选对分支。
- **带 `row` / `rows` 的动作**：先看该段卡面语义——出现「免费获得」按**被拿走的交易行卡的价值**估值；
  出现「销毁交易行…获得等同于其费用的战斗」按**该卡费用**估战斗收益；纯「销毁交易行」只在对手买得起的高价值卡上用来卡人。
- **带 `targets` 的动作**（`scrapOwn`（含「至多 N 张」的 `minScrap`）`/ recycle / discardThenDraw / depot`）：
  逐张按「失去它 − 换来的过滤或抽牌」计价，`depot` 还会区分 `resource:'trade'|'combat'`；**空集动作**（合法但等于不发动）默认拿 0 分不选。
- **带 `targetId` 的动作**（拆基地、`destroyBase`）：目标基地按「前哨 + 剩余防御 + 牌面价值」打分，
  `targetId: null` 的分支视为「空目标」直接 0 分，不做无用功。
- **未知动作类型**：所有未知 `type` / 未知 `ability` 键都不抛异常——未知能力键进入兜底打分桶，
  未知动作类型由 `fallback()` 返回 `endTurn`（没有 `endTurn` 时返回 `legalActions[0]`）。

## 四、团队回合结构变化带来的估值调整

1. **整队轮流（0→2→4→1→3→5 / 0→2→1→3）**：`transfer` 的价值从「下回合才到账」变成「紧接着就能用」，
   于是把「换手前把剩余资源交出去」写成固定收尾相位；同时敌人也会连打三名队友，前哨的保护价值上调（购买前哨 +1.1）。
2. **队末才清算**：`s.damage` 在整队行动完才清空，所以
   - 攻击判定从「本回合打穿才算数」放宽为「本回合打穿 **或** 只差 1–2 点且是敌方前哨（团队模式）」；
   - 队友留在同一目标上的伤害会在 `defLeft()` 里被扣掉，补刀优先级提高。
3. **起手牌按队发放（偶数座位 3 张 / 奇数座位 5 张）**：手牌数不再当常量，`deckAverage()` 与实际 `hand` 长度驱动购买门槛，
   后手队不会因为「以为自己是 5 张」而低估起手质量。
4. **全队共享前哨保护**：`legalActions` 里可能整段没有「攻击敌方玩家」的动作，脚本不会把它当成「没有目标」，
   而是自然落到攻击基地分支（拆前哨解封全队），这条在 hydra3 里出现频率最高。
5. **权威在队上 vs 在个人身上**：`team2v2 / hydra3` 用共享池（打谁都一样，选权威比例最低的目标即可），
   `emperor` 用个人池（优先削对位提督、后期优先大将），两种口径在 `startAuthorityOf()` 与攻击目标选择里分开处理。

## 五、取舍与已知弱点

- **保留「只买高于牌库平均的牌」的门槛**：好处是不稀释牌库，坏处是 6 牌包混洗时交易行里可能长期没有过线的牌，
  于是会出现「满手贸易却什么都不买」。这是刻意的保守取舍（后期废牌比空过更伤）。
- **文本解析是启发式的**：条件收益（「若控制两座以上基地」）统一按 50% 折价，个别新卡会被低估或高估；
  只认识的句式之外的卡按 `cost × 0.9` 兜底，宁可低估也不当炸弹。
- **不做跨座位推演**：`transfer` 只按「下一个行动的队友」给，不猜测队友会用战斗打哪座基地，
  因此偶尔会把战斗交给一个用不上的人（但这部分资源本来也会清零，损失可接受）。
- **firstBlood 的降额是保守的**：只对「右手边是我」的目标下杀手，若局面逼着必须抢先减员，可能错过唯一一次获胜窗口。
- **emperor 的 `moveCard` 使用偏少**：只在贸易确实没别的用途时才移交，不会主动用贸易换「给队友一张牌」。
- **没有做跨回合记忆建模**：`memory` 只记录决策次数与买过的探索者数量，不做对手风格推断。
