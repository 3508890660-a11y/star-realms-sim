自选策略：协同滚雪球

# 策略名称与选择理由

**协同滚雪球（Synergy Snowball）**。

理由：在 1v1《星域奇航》中，最稳健的取胜路径是「卡差」——优先打出同阵营飞船触发「同盟」抽牌 / 获权威 / 获战斗，建立越滚越大的资源与手牌雪球；同时用战斗先拆掉敌方前哨（封锁直伤的墙），再对权威直伤抢杀。相比纯快攻，它有更久的续航；相比纯经济，它更早形成压制，因此五模式与 core / colonyWars / events 任意组合都适用。

# 核心思路

1. **铺场优先**：每回合先把所有手牌中的飞船 / 基地打出来，既立即获得其主效果，又能凑齐同阵营两张以触发「同盟」。
2. **同盟驱动卡差**：同盟的「抽牌」「获权威」「获战斗」是复合收益，抽到更多牌 → 下回合能打更多 → 雪球越滚越大。评分时对能触发同盟的卡明显加分。
3. **建设雪球**：用积累的贸易按「性价比 + 阵营协同」购买交易行最优卡，廉价高协同卡（如贸易机器人、联邦穿梭机、虫群战机）优先，中后期补旗舰 / 指挥舰 / 主宰母舰等重型卡。
4. **战斗用于拆墙与抢杀**：战斗不是盲目倾泻，而是先拆敌方前哨解除封锁，再对权威直伤；能一击致死就直接收下。

# 动作优先级

每个决策点只从 `legalActions` 中原样返回一个对象，顺序如下：

1. **待决（pending）**：`discard` / `selectScrap` 弃（销）价值最低的牌；`targetDiscard` 任意合法目标；`eventChoice` 按低损失原则（见下）。
2. **致死直伤**：存在 `attack` 到玩家且 `amount >= 对手权威` 时立即执行，直接获胜。
3. **打出（play）**：手牌中评分最高的飞船 / 基地（复制舰优先复制场上最强飞船；选项牌按当前局面选数值更高的分支）。
4. **能力（ability）**：发动有益的同盟 / 基地主能力 / 可选能力 / 补刀销毁（探索者或 ≥5 战斗的销毁）；纯「销毁自己牌」且无收益的同盟跳过。
5. **购买（buy）**：在可负担卡中按 `cardScore` 选最高分（含 cost 惩罚与阵营协同加成），探索者作为兜底填充。
6. **攻击（attack）**：优先级为「致死直伤 > 拆敌方前哨 > 直伤抢杀（优先打权威最低对手）> 拆非前哨敌方基地」。
7. **兜底**：无更优动作时返回 `endTurn`，极端情况下回退到 `actions[0]`，绝不抛异常或死循环。

# 模式与扩展适配

- **五模式**：`standard` 单对手直接套用上述逻辑；`ffa` / `hunter` / `firstBlood` 下「直伤抢杀」会自动选择权威最低的存活对手，有利于削减人头与触发先血规则；`team2v2` 下攻击按队伍权威结算，直伤同样以对手权威为致死判据，`transfer` 动作存在但默认不使用（不影响合法性，可安全留到结束回合）。
- **三扩展**：`core` / `colonyWars` / `events` 任意组合均兼容。殖民战争新卡通过同一套文本解析与评分函数自动估值，无需特判；事件通过 `eventChoice` 兜底处理。
- **数值来源**：接口只暴露卡牌 `text` 描述，不暴露结构化效果字段，因此脚本用正则从中文描述中提取「贸易 / 战斗 / 权威 / 抽牌」数值来估值，对所有卡牌通用。

# 事件与 2V2

- **事件（`eventChoice`）**：黑洞弃掉价值最低的两张（避免 -8 权威）；轨道轰击拆掉最弱的己方基地（优于 -6 权威）；彗星销毁价值最低的两张压缩牌库；跃迁把价值最低的两张放回牌库顶、保留最好的在手上。无对应事件类型时回退到第一个合法动作。
- **2V2**：阵营协同、致死判据、事件兜底均与单人一致；队友预留（`transfer`）为可选项，本策略不主动预留，避免误伤自身资源，但仍能正确应对己方被预留资源（引擎在回合开始自动接收）。

# 取舍与已知弱点

- **弱点 1 —— 不主动预留给队友**：在 2V2 中未利用 `transfer` 把多余贸易 / 战斗让给队友，团队协同上限不如专门调度型脚本。
- **弱点 2 —— 文本估值粗糙**：依赖 `text` 正则解析，对极少数条件型描述（如「每打出过一张某阵营牌便抽牌」）只能近似估算，可能略低估此类卡的收益。
- **弱点 3 —— 不囤牌**：基本每回合打光手牌，遇到对手强制弃牌（`discard` / `targetDiscard`）时暴露面较大，但已用「弃最低价值牌」最小化损失。
- **取舍**：放弃纯快攻的极端速度与纯经济的极致展开，换取更稳的续航与更通用的模式 / 扩展兼容；攻击只用于「拆墙 + 抢杀」而非无脑铺战斗，保证每一分战斗都产生确定收益。
